# aws-poly 运行结果与策略变更说明（2026-06-07 至 2026-07-02）

## 1. 统计范围与口径

- 服务器：`aws-poly`，服务与日志时区均为 UTC。
- 用户要求区间：2026-06-07 00:00 UTC 至 2026-07-02 01:17 UTC（北京时间 2026-06-07 08:00 至 2026-07-02 09:17）。
- 实际可用 summary 从 2026-06-07 06:50 UTC 开始；共 6,986 个 5 分钟周期。
- 下单：summary 中生成的订单；提交：CLOB 返回 `success=true` 且有 order ID。
- 成交：用 deposit wallet 的 CLOB `get_trades` 按 order ID 回连，包含 maker、taker 和部分成交。
- 获胜订单：有任意真实成交且所买 YES/NO 与 Gamma 最终结算一致的 order ID。一个订单即使分多笔成交也只计一次。
- 成交概率同时给出订单口径（有成交的 order ID / 成功提交 order ID）与份额口径（成交 shares / 请求 shares）。
- PnL 按真实成交份额计算：赢时 `shares × (1 - fill_price)`，输时 `-shares × fill_price`；未扣 gas、交易费、返佣和资金成本。
- “提交重放 PnL”是假设成功提交订单全部按限价足额成交的理论值，不能视为真实收益。
- “模型概率”使用所选方向概率 `max(p_up, 1-p_up)`，不是固定使用 `p_up`。

## 6. 当前下单策略

1. systemd timer 每 5 分钟在 `xx:01/5:08` UTC 运行一次，runtime 为 live。
2. 分类模型是 `20260611_catboost_calendar_coordinate_search`：CatBoost、569 个特征、不校准；全局阈值 `t_up=0.5792857`、`t_down=0.4314286`，实际另按星期 × Asia/Europe/US 时段使用日历阈值表。
3. 只下第一腿，第二腿关闭；固定请求 5 shares，价格范围 0.10–0.99。
4. 价格估计器是 `20260612_catboost_quantile_winner_price_baseline`，CatBoost q80、1,021 个特征。首单价格模式为 `min_q80_final_price_and_best_ask_offset`，实际代码计算 `min(q80_price, best_ask - 0.01)`。虽然配置中 `price_cap=0.55`，q80 分支没有应用 `price_cap`，所以该 cap 当前无效。最近 500 个 summary 中有 254 单高于 0.55，观察到的示例最高为 0.85。
5. execution edge 过滤当前关闭。成功提交后进程等待 60 秒，再查询订单状态：有未成交余量则调用 CLOB cancel；已经成交或不再 open 则跳过。最近 1,000 个周期中，294 次调用 cancel，427 次因已成交或不再 open 跳过。不过这 294 次记录的 `cancel_response` 全部为 null，代码也没有再次查询订单状态，因此只能证明“执行了撤单调用”，不能证明撤单最终生效。启用市场可交易、best bid、幂等和每窗口最多 2 单等 guard（实际因第二腿关闭通常最多 1 单）。
6. 服务读取 deploy artifact 中的模型、特征列清单和阈值，但仍由执行进程拉取 Binance 1m、1s 和 aggTrades，并通过 `RuntimeInferenceEngine` 调用共享 `src` feature builder 实时构建 BTC 特征。这里的“一致性”是线上和离线共用同一套 builder，不是“执行层不计算特征”。

## 7. 结论

该区间真实成交后为正收益，但优势很薄：+87.94 USDC、ROI 0.78%。核心问题集中在模型概率 0.5–0.6 和下单价 0.5–0.6 两个桶；高置信桶胜率更高，但成交率明显更低。当前策略已在 06-12 改为 q80 价格估计、0.55 cap 和 60 秒撤单，后续评估应把 06-12 前后分开，避免把 11 次策略状态混合后的总体均值直接当作当前策略预期。

原始分析产物：`artifacts/aws_poly_since_20260607_analysis.json`。复算脚本：`scripts/analysis/summarize_aws_poly_window.py`。
