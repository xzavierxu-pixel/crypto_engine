# 20260612 CatBoost Stacked Meta Model 实验分析报告

## 1. 实验结果概述
本次实验 (`20260612_catboost_continuation_reversal_stacked_meta_model`) 的目标是通过软融合（Soft Stacking）的方式，将“顺势专家(Continuation)”和“反转专家(Reversal)”的预测结果以及其他宏观特征输入到一个浅层的 Meta-Model 中进行最终的 UP/DOWN 决策。

实验成功运行并生成了未降级的有效结果：
*   **最佳变体**: `experiment_a_expert_only` (仅使用专家输出和基础状态特征，不引入额外的 50 个市场特征)。
*   **Selection Score**: `0.57485` -> `0.59262` (小幅提升)
*   **Utility**: `0.2674` -> `0.2749`
*   **覆盖率 (Coverage)**: `70.0%` -> `0.70.5%` (满足 `>0.70` 约束)
*   **整体胜率 (Accepted Sample Accuracy)**: `69.10%` -> `69.49%`

虽然结果成功打破了基线并且成功通过了所有约束验证，但 **提升幅度显得相对保守，并没有实现跃升式的增长**。

---

## 2. 核心数据发现：Meta-Model 的“顺势坍缩”

通过深度解析 `report.json` 和分析输出数据，我们发现了 Stacked Meta-Model 没有大幅提升的核心原因：**模型在追求全局评分最大化的过程中，彻底放弃了反转交易 (Reversal Trades)，坍缩成了一个更加聪明的“纯顺势模型”**。

这可以通过以下几个关键的数据对照得到完美印证：

### 2.1 开仓方向与第一分钟方向的绝对绑定
从 `validation_metrics` 和诊断切片 (Diagnostic Slices) 中提取的数据如下：
*   **总做多开仓 (`up_prediction_count`)**: 2423 笔。
    *   同时，当 `first_minute_side == YES` 时，被模型接受开仓的总笔数 (`accepted_count`) **恰好也是 2423 笔**。
*   **总做空开仓 (`down_prediction_count`)**: 2844 笔。
    *   同时，当 `first_minute_side == NO` 时，被模型接受开仓的总笔数 (`accepted_count`) **恰好也是 2844 笔**。

**这意味着：Stacked 模型做到了 100% 的同向开仓。** 只要开盘第一分钟是涨的，它要么预测涨，要么选择放弃 (`ABSTAIN`)，**绝对不会**去预测跌。它实际上退化成了一个 Continuation Only 策略。

### 2.2 反转预测胜率为零
在 `actual_regime`（实际结算方向分类）切片中：
*   **`continuation` (结算方向与第一分钟同向)** 的样本，`accepted_accuracy` 为 **100%**。
*   **`reversal` (结算方向与第一分钟反向)** 的样本，`accepted_accuracy` 为 **0.0%**。

因为模型永远只顺着第一分钟方向押注，所以任何时候只要行情发生了真实的反转，只要模型当时没管住手开了仓，它就100%会亏损。

## 3. 为什么表现没有大幅提升？

### 3.1 “反转专家”被降级为“避险过滤器”
通过查看 `stacked_feature_importance.csv`，前五大特征分别是：
1. `continuation_p_up` (21.84%)
2. `continuation_minus_reversal_p_up` (13.68%)
3. `first_minute_side_no` (13.66%)
4. `first_minute_side_yes` (12.05%)
5. `continuation_confidence_minus_reversal_confidence` (9.86%)

而代表纯反转意图的 `reversal_p_up` 重要性仅为 2.31%。
这表明，Meta-Model 并没有真的把反转专家的信号当成“这里可以反向开仓赚取超额收益”的指令。相反，它将其视为一个**“危险警告器”**：当“顺势专家”认为可以做，但“反转专家”给出了非常强烈的反向警告时（体现在 `continuation_minus_reversal_p_up` 缩小），Meta-Model 的选择是**直接 `ABSTAIN` (不开仓避险)**，而不是听从反转专家去反向开单。

### 3.2 预测难度的天然不对称性
机器学习模型 (CatBoost) 优化的目标是最大化全局准确率/对数损失。在当前的微观尺度下：
*   顺势交易的天然胜率本身就更高（基线已经在 70% 左右）。
*   反转交易属于逆势博弈，特征噪声大，胜率极难提升。
当我们将这两个专家糅合到一个浅层 Meta-Model 中进行统一的 `t_up/t_down` 阈值切割时，模型由于“趋利避害”，自然会放弃风险极高的反转交易路线，只专注于在原本的顺势交易里“挑出最好捏的柿子”。

### 3.3 提升从何而来？
实验能从 0.5748 提升到 0.5926，本质上就是因为它**利用了反转专家的负面置信度，更精准地排除了那些高风险的顺势交易**。它剔除了一部分本来会亏损的顺势单子，使得胜率略微上升了 0.4%，从而带动整体 Utility 和 Selection Score 的提升。
但也正因为它没有开发出反转交易这一块“新大陆”，导致它的增量仅仅停留在“优化过滤条件”的层面，没有产生质变。

---

## 4. 结论与后续建议

**实验结论：软融合 (Soft Stacking) 机制是有效的，它成功规避了之前硬路由实验带来的覆盖率断崖式下跌问题，并创下了当前 Selection Score 的新高。但代价是模型通过数学上的捷径，将策略“降维”成了纯顺势策略的智能过滤版。**

**后续策略建议**：
1.  **接受局部最优**：如果业务上“不强求”一定要做反转，那么这个 `experiment_a_expert_only` 模型目前就是非常优秀且健壮的基线。它安全、符合常理（顺势而为）、利用了多模型的交叉验证来控制回撤。
2.  **强制解耦评估 (若必须做反转)**：如果未来必须捕获反转利润，不能把两者放在同一个 Meta-Model 下做统一阈值输出。你需要设计一套机制，给“顺势环境”和“反转环境”配置**完全独立的验收阈值和计分板**，否则算法永远会为了保住顺势的高胜率而主动“绞杀”反转逻辑。
