# Execution Engine

The execution engine connects the accepted BTC/USDT 5-minute Polymarket baseline to paper, shadow, or live Polymarket execution. It is a runtime adapter, not a second model system.

Model logic, calibrator logic, feature columns, thresholds, and validation metrics come from the deploy artifact under:

```text
execution_engine/deploy/baseline
```

The execution layer must not recompute BTC features independently.

## Baseline Files

The deploy directory should contain:

```text
execution_engine/deploy/baseline/
  artifact_manifest.json
  catboost_lgbm_logit_blend.binary.pkl
  platt_logit.binary.pkl
  metrics.json
  threshold_search.json
  probability_reference.json
  feature_importance.csv
```

Runtime inference requires `artifact_manifest.json`, the model pickle, and the calibrator pickle. The other files are for audit and deployment checks.

In `execution_engine/config.yaml`, keep `baseline.model_file` and `baseline.calibrator_file` as `null` unless you intentionally need to override manifest resolution:

```yaml
baseline:
  artifact_dir: execution_engine/deploy/baseline
  model_file: null
  calibrator_file: null
```

## Local Paper Smoke Test

Create a local config:

```bash
cp execution_engine/config.example.yaml execution_engine/config.yaml
```

Keep paper mode and order submission disabled:

```yaml
runtime:
  mode: paper
orders:
  enabled: false
```

Prewarm runtime data:

```bash
. .venv/bin/activate
python execution_engine/prewarm.py \
  --config execution_engine/config.yaml \
  --cache-output artifacts/state/execution_engine/prewarm \
  --print-json
```

Run one paper cycle:

```bash
. .venv/bin/activate
python execution_engine/run_once.py \
  --config execution_engine/config.yaml \
  --mode paper \
  --print-json
```

Outputs are written under:

```text
artifacts/logs/execution_engine/live.jsonl
artifacts/logs/execution_engine/summaries/
```

## Linux Deploy

Canonical deployment path:

```text
/home/ubuntu/opt/crypto_engine
```

Do not run production services from `/opt/crypto_engine`. If an old checkout exists there, stop any service using it and remove it after confirming `/home/ubuntu/opt/crypto_engine` is active.

Prepare code:

```bash
mkdir -p /home/ubuntu/opt
cd /home/ubuntu/opt
git clone -b baseline https://github.com/xzavierxu-pixel/crypto_engine.git crypto_engine
cd /home/ubuntu/opt/crypto_engine
```

Install runtime dependencies:

```bash
python3 --version
sudo apt update
sudo apt install -y python3.12-venv python3-pip git
rm -rf .venv
bash execution_engine/scripts/install_linux.sh
```

The installer installs `execution_engine/requirements.txt`, including the model runtime dependencies required by the current artifact. If dependency drift causes `InconsistentVersionWarning` for sklearn artifacts, use the version recorded for the artifact environment.

Create runtime config:

```bash
cp execution_engine/config.example.yaml execution_engine/config.yaml
vim execution_engine/config.yaml
```

Verify deploy files:

```bash
ls execution_engine/deploy/baseline
python - <<'PY'
from execution_engine.artifacts import load_baseline_artifact
from execution_engine.config import load_execution_config
cfg = load_execution_config("execution_engine/config.yaml")
artifact = load_baseline_artifact(cfg.baseline)
print(artifact.manifest["training_mode"])
print(artifact.t_up, artifact.t_down)
print(len(artifact.feature_columns))
PY
```

Expected:

```text
online_full_train
0.62 0.415
1016
```

## Live Mode Checklist

Before enabling live orders:

1. Confirm `execution_engine/config.yaml` points to the tracked deploy artifact.
2. Confirm `runtime.mode: paper` and `orders.enabled: false` have passed a smoke test.
3. Confirm `execution_engine/secrets.env` contains CLOB credentials and the correct wallet mode.
4. Confirm Polymarket mainnet settings:

```yaml
polymarket:
  host: https://clob.polymarket.com
  gamma_base_url: https://gamma-api.polymarket.com
  chain_id: 137
```

5. Confirm the latest summary contains sane `market.slug`, `target_token_id`, `best_bid`, `p_up`, `t_up`, `t_down`, and `orders`.
6. Confirm wallet approval and funding.
7. Confirm idempotency state is writable:

```bash
mkdir -p artifacts/state/execution_engine
touch artifacts/state/execution_engine/idempotency.json
```

Only then switch:

```yaml
runtime:
  mode: live
orders:
  enabled: true
```

## Systemd Timer

Use systemd timers for production scheduling. Prewarm at the 5-minute boundary, then run live execution 20 seconds later.

```ini
# /etc/systemd/system/execution-engine-prewarm.service
[Unit]
Description=Crypto Engine prewarm runtime features
After=network-online.target
Wants=network-online.target

[Service]
Type=oneshot
User=ubuntu
Group=ubuntu
WorkingDirectory=/home/ubuntu/opt/crypto_engine
ExecStart=/home/ubuntu/opt/crypto_engine/.venv/bin/python execution_engine/prewarm.py --config execution_engine/config.yaml --cache-output artifacts/state/execution_engine/prewarm
```

```ini
# /etc/systemd/system/execution-engine-prewarm.timer
[Unit]
Description=Prewarm Crypto Engine runtime features every 5 minutes

[Timer]
OnCalendar=*-*-* *:00/5:00
AccuracySec=1s
RandomizedDelaySec=0
Persistent=false
Unit=execution-engine-prewarm.service

[Install]
WantedBy=timers.target
```

```ini
# /etc/systemd/system/execution-engine.service
[Unit]
Description=Crypto Engine Polymarket execution cycle
After=network-online.target
Wants=network-online.target

[Service]
Type=oneshot
User=ubuntu
Group=ubuntu
WorkingDirectory=/home/ubuntu/opt/crypto_engine
EnvironmentFile=/home/ubuntu/opt/crypto_engine/execution_engine/secrets.env
ExecStart=/home/ubuntu/opt/crypto_engine/.venv/bin/python execution_engine/run_once.py --config execution_engine/config.yaml --mode live
```

```ini
# /etc/systemd/system/execution-engine.timer
[Unit]
Description=Run Crypto Engine execution cycle every 5 minutes

[Timer]
OnCalendar=*-*-* *:00/5:20
AccuracySec=1s
RandomizedDelaySec=0
Persistent=false
Unit=execution-engine.service

[Install]
WantedBy=timers.target
```

Enable:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now execution-engine-prewarm.timer
sudo systemctl enable --now execution-engine.timer
```

Inspect:

```bash
systemctl list-timers 'execution-engine*'
journalctl -u execution-engine.service -n 100 --no-pager
```

## Live Full-Flow Order Test

Before enabling the timer on a live server, run the full flow once:

```bash
. .venv/bin/activate
python execution_engine/scripts/test_full_flow_order_until_success.py \
  --config execution_engine/config.yaml \
  --secrets execution_engine/secrets.env \
  --force-on-abstain \
  --max-attempts 10 \
  --sleep-seconds 30 \
  --print-json
```

Interpretation:

- `success_type=run_once_submitted`: the real strategy signal passed thresholds and submitted a live order.
- `success_type=forced_order_submitted`: the strategy abstained, but the live Polymarket order path was verified with one minimum-price test order.
- `425 service not ready`: Polymarket CLOB is not ready for that BTC 5-minute market yet; retry after a short delay.

Do not print or copy `execution_engine/secrets.env` values while running this test.

## Troubleshooting

`market_not_found`: Polymarket current BTC 5-minute slug was not found. Check system clock, Gamma API availability, and market window alignment.

`missing_best_bid`: target token has no best bid; execution skips order submission.

`Runtime feature frame is missing ... baseline features`: runtime data cannot build all baseline features. Check 1-minute/1-second inputs, lookback, and the artifact feature list.

`py-clob-client-v2 is required`: deployment environment is missing the CLOB v2 client; rerun `execution_engine/scripts/install_linux.sh`.

`ModuleNotFoundError: No module named 'sklearn'`: install runtime dependencies with `python -m pip install -r execution_engine/requirements.txt`.

`idempotency_key_already_seen`: the same window/token already had an order plan submitted; default behavior is to skip to prevent duplicate orders.
