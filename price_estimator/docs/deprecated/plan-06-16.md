# Heteroskedastic Conditional-Margin Safe Lowest Price 方案

目标：把 Pareto 前沿真正往左下推（同 coverage 下更小 gap），而不只是在前沿上选点。

做法 = capped_quantile baseline + 条件化 margin（异方差 sigma 模型）+ 高 sigma 退化到 p_side。

参考：
- baseline 选点：`docs/capped_quantile_safe_lowest_price_requirements.md`
- 评估口径：`docs/safe_lowest_price_regression_asymmetric_logcosh.md`
- 已有 quantile：`scripts/train_catboost_quantile.py`（输出 pred_q70/q80/q90）
- 已有不确定性特征源：`src/data/second_level_feature_packs.py`

---

## 1. 核心思想

前沿位置由 `Var(lowest_price | X)` 决定。全局常数 margin 对所有样本花同样的安全预算，是次优的。

三条杠杆，本方案全部使用：

```text
1. 异方差 margin：margin_i = q · sigma_hat(X_i)，sigma 小的样本少花预算 → 平均 gap 下降
2. 不确定性特征集：降低 sigma_hat 的估计误差 / 解释更多条件方差
3. 高 sigma 退化：sigma_hat 太大的样本直接报 p_side（最保守合法价），不强行压低
```

约束（始终成立）：

```python
buffer = 0.01
lowest_safe = lowest_price + buffer      # inference 不可见
p_pred <= p_side                          # 硬约束
```

---

## 2. 三段式结构

### Stage A：Center 模型（已有，复用）

复用已训练的 quantile 模型，取一个中心列作为 `mu`：

```text
mu_i = pred_q50  （若无 q50，用 pred_q70 作为偏保守中心，二选一做对照）
```

不重训。Stage A 只负责给出 lowest_price 的条件中心估计。

### Stage B：Sigma 模型（新增，核心）

训练一个回归模型预测条件不确定性：

```python
residual_i = target_raw_i - mu_i          # 仅训练集，mu 为 Stage A 的 out-of-fold 预测
sigma_target_i = abs(residual_i)
sigma_hat_i = sigma_model(X_i)
sigma_hat_i = max(sigma_hat_i, sigma_floor)   # sigma_floor = 0.01
```

要点（吸取 local_min 实验教训）：

```text
1. mu 必须用 out-of-fold / 时间外预测来算 residual，否则 fit residual≈0，sigma 学不到真实不确定性
2. sigma_model loss 用 log-cosh 或 Huber，对 |residual| 直接回归
3. 模型选择只看 calibration / validation 的 sigma 校准，不看 train
```

### Stage C：条件化 margin + 退化（校准集上定标）

在 calibration set 上算归一化分位（normalized split-conformal）：

```python
score_i = (target_raw_i - mu_i) / sigma_hat_i
q = quantile(score_i, coverage_floor)     # 例如 0.70 分位
```

inference / validation：

```python
margin_i = q * sigma_hat_i
p_raw_i  = mu_i + margin_i

# 高 sigma 退化：不确定性太大就报最保守合法价 p_side
if sigma_hat_i > sigma_high:
    p_pred_raw_i = p_side_i
else:
    p_pred_raw_i = min(p_raw_i, p_side_i)

p_pred_i = ceil(p_pred_raw_i * 100 - 1e-9) / 100
```

```text
sigma_high：在 calibration 上按 sigma_hat 的分位数设（如 q80/q90），扫描选点
退化到 p_side 的样本一定满足 p_pred<=p_side，且 feasible 时必 covered
```

## 3. 不确定性特征集（新增 1 个，可选但推荐）

Sigma 模型先用现有 deploy 特征 + 以下已有二级特征作为 `sigma_feature_set`。
这些 pack 已存在于 `src/data/second_level_feature_packs.py`，无需新造数据。

```text
realized vol  : sl_rv_30s, sl_mirror_rv_10s/30s/60s
order flow     : sl_taker_imbalance_30s, sl_ofi_30s
microstructure : sl_spread_bps, sl_bid_ask_qty_imbalance, sl_microprice_premium
depth          : sl_depth_imbalance_5, sl_weighted_depth_imbalance_5
context        : p_side, direction_confidence, time_to_lowest_trade_sec_bucket
```

理由：`lowest_price` 短期下行幅度的方差主要由波动率 / 订单流失衡驱动，这些特征直接解释 sigma。

实验设计：

```text
sigma_v0: 仅 deploy 特征
sigma_v1: deploy 特征 + sigma_feature_set
对照 sigma_v1 是否降低 validation covered_normalized_lowest_safe_gap（同 coverage）
```

---

## 4. 评估（复用 safe_lowest 口径）

只在 covered 样本上统计 `q25/median/mean/q75`：

```python
covered = (p_pred >= lowest_safe) & (p_pred <= p_side)
coverage = covered.mean()

pred_to_p_side_distance      = p_side - p_pred
pred_to_lowest_safe_distance = p_pred - lowest_safe
normalized_lowest_safe_gap   = (p_pred - lowest_safe) / (p_side - lowest_safe)   # denom>0
```

feasible 拆分（train/validation 诊断，inference 不可用）：

```python
feasible = lowest_safe <= p_side
max_possible_coverage = feasible.mean()
coverage_feasible     = covered[feasible].mean()
```

退化诊断（新增，必报）：

```text
fallback_rate          = mean(sigma_hat > sigma_high)
fallback_coverage      = covered[fallback].mean()
non_fallback_coverage  = covered[~fallback].mean()
non_fallback_norm_gap  = normalized_lowest_safe_gap[~fallback]   # 真正反映模型质量
```

---

## 5. 选点规则

两个旋钮：`q`(coverage_floor) 与 `sigma_high`。在 calibration 上扫描，在独立 validation 上报告：

```text
1. 过滤 coverage >= coverage_floor（建议同时报 0.60 / 0.70 / 0.80）
2. 最小化 covered_normalized_lowest_safe_gap.mean
3. tie-break：median，再 coverage 高者
4. 记录 fallback_rate（退化太多说明 sigma 普遍偏大，需回到特征/center）
```

成功判据：

```text
sigma_v1（条件化 margin）在固定 coverage 下，
covered_normalized_lowest_safe_gap.mean 低于 capped_quantile baseline（全局 margin）。
否则说明 sigma 没学到有效信息，回退 baseline。
```

## 6. 与已有方案的关系

```text
capped_quantile baseline = 本方案在 sigma_hat ≡ 常数 时的特例（全局 margin）
本方案新增：
  + Stage B sigma 模型（异方差，核心，移动前沿）
  + sigma_feature_set（降低条件方差）
  + 高 sigma 退化 p_side（用 fallback_rate 换更低 covered gap，不产生非法报价）
复用：已训练 quantile center、capped/ceil/p_side 约束、safe_lowest 评估指标
```

---

## 7. 实施顺序

```text
1. 用现有 quantile 产出 mu（out-of-fold residual）
2. 训练 sigma_v0（仅 deploy 特征），跑通三段式 + 评估
3. 构建 sigma_feature_set，训练 sigma_v1，对照前沿
4. 扫描 (coverage_floor, sigma_high)，画 coverage–gap 前沿，选操作点
5. 仅当 sigma_v1 前沿优于 baseline 才推进
```
